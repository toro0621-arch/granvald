## 顔グラ3人分（1枚の資料）

```
添付の「キャラクター顔グラフィック」の資料と、まったく同じ形式・同じ絵柄（同じ画家が描いたように）で、新しい3人分の資料を1枚描いてください。
形式：上に題名の帯、その下に3人分の縦長のパネルを横に並べ、各パネルの上に名前の札、下に短い説明文。パネルの中は胸から上の人物画で、背景は明るい灰色の無地。
絵柄：添付と同じアニメ調。細めの線、陰影のある落ち着いた塗り。太い線のマンガ風やベタ塗りにしない。
世界観：中世ヨーロッパ風のファンタジーの帝国。服は軍服で、現代の服にしない。

1人目「シュタール」：64歳の男性。帝国軍の元帥で、名門伯爵家の当主。三十年前の大会戦を指揮官として戦い抜いた、帝国一の名将。厳格で清廉。短く刈った白髪と、きれいに整えた白い口ひげ。深いしわの刻まれた、いかめしい顔。鋭く落ち着いた灰色の目。背筋がまっすぐ伸びている。濃い灰色の元帥の軍服に、銀の飾り緒と、元帥の印の金の肩章。勲章は少なく、古い戦傷の勲章を一つだけ付けている。表情は厳しく、威厳があるが、冷たくはない。太らせない。
2人目「ユリウス」：24歳の男性。皇族の若い将校で、帝国軍総帥の孫。祖父のやり方を嫌う、筋を通す実直な青年。整った顔立ちで、まっすぐな濃い金色の髪を短めに整えている。澄んだ緑がかった青い目。白い詰め襟の皇族の軍服に、金の飾り緒と、胸に小さな皇族の紋章（金の双頭の鷲）。表情はまじめで凛としていて、少し思いつめたような真剣さがある。軽薄な笑みは浮かべない。
3人目「ベルトルト」：55歳の男性。帝国軍務省の兵站局長で、少将。名門侯爵家の分家の出。軍の補給を管理する役人のような軍人で、戦場の経験は少ない。小太りで、てかてかした頬。薄くなった茶色の髪をなでつけ、細い口ひげ。小さく落ち着きのない目。紺色の将官の軍服に、金の飾り緒。胸に兵站局の印（交差した鍵と麦の穂）。表情は、愛想笑いを浮かべているが、目は笑っておらず、どこか怯えている小心者の顔。
```
