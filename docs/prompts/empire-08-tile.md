## 帝都の東の城壁と運河（1枚の資料）

```
添付の地形タイルの資料と、まったく同じ形式・同じ絵柄（真上から少し斜めに見下ろした、ファンタジーRPGのドット絵風のマップタイル）で、新しいタイルの資料を1枚描いてください。
形式：上に小さな見出しの文字、その下にタイルを並べる。タイルとタイルのあいだと、まわりの背景は、マゼンタ（#FF00FF）一色のベタ塗り（グラデーションなし）。
地面について：添付の資料とちがい、タイルの下に草地や地面は描かないでください。城壁や橋や建物そのものだけを描き、そのまわりと、すき間から見える部分もすべて同じマゼンタにしてください。足元の影も描かないでください。
世界観：中世ヨーロッパ風のファンタジーの帝国の都。ビル・鉄骨・コンクリート・街灯など近代的なものは描かないでください。

並べるタイル（それぞれ1マス＝正方形。大きさは添付の資料の1マスと同じ）：
1. 都の城壁（縦）：灰色の大きな切り石を積んだ、厚くて高い城壁。マスの上はしから下はしまで縦に通っている。上には、凸凹の胸壁（ぎざぎざの低い壁）と、兵が歩く通路が見える。
2. 城門（縦の城壁につく）：1と同じ城壁に作られた、両脇に丸い塔のある城門。門は右（城壁の外）へ向かって開いていて、太い木の扉と鉄の金具。
3. 石の橋（縦）：運河をまたぐ、灰色の石の橋。マスの上はしから下はしまで縦に渡っていて、両側に低い石の欄干。橋の下の水は描かず、マゼンタにしてください。
4. 穀物倉庫（横長、2マスぶん）：真上から見た、石とれんがでできた大きな三階建ての穀物倉庫。赤茶色の瓦屋根で、屋根の棟が横に通る。手前（下）の壁に大きな扉と、そのそばに積まれた麦袋の山。
5. 荷揚げ場の石段：運河の岸に作られた、水面へ下りる石の階段と、小舟をつなぐ木の杭。
```
