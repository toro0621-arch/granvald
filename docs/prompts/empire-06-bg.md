```

場所：中世ヨーロッパ風のファンタジーの帝国の、帝都へ向かう山あいの峠道。
構図：峠道を少し高いところから見下ろす。両側に切り立った灰色の岩の崖がそびえ、崖の上には針葉樹がまばらに生えている。そのあいだを、土の道が曲がりくねって奥へ続いている。道には轍のあと。道の奥、峠の向こうに、遠く霞んだ大きな城壁の都の影がかすかに見える。崖の上の岩陰が、何かが潜んでいそうに暗い。
時間と空気：夏の昼。青い空に白い雲。崖が道に濃い影を落としていて、静かだが張りつめた空気。
人物、ロボット、文字は入れないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```
