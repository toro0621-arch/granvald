## 1. 古い兵站倉庫の敷地（1枚の資料）

```
添付の地形タイルの資料と、まったく同じ形式・同じ絵柄（真上から少し斜めに見下ろした、ファンタジーRPGのドット絵風のマップタイル）で、新しいタイルの資料を1枚描いてください。
形式：上に小さな見出しの文字、その下にタイルを並べる。タイルとタイルのあいだと、まわりの背景は、マゼンタ（#FF00FF）一色のベタ塗り（グラデーションなし）。
地面について：添付の資料とちがい、タイルの下に草地や地面は描かないでください。建物や塀そのものだけを描き、建物や塀のまわりと、すき間から見える部分もすべて同じマゼンタにしてください。足元の影も描かないでください。
世界観：中世ヨーロッパ風のファンタジーの帝国軍が、三十年前まで使っていた古い補給基地。いまは使われておらず、古びて、ところどころ傷んでいる。ビル・鉄骨・コンクリート・トタン屋根など近代的なものは描かないでください。

並べるタイル（それぞれ1マス＝正方形。大きさは添付の資料の1マスと同じ）：
1. 石の塀（横）：灰色の古い石を積んだ低い塀。マスの左はしから右はしまで、まっすぐ横に通っている。ところどころ石が欠け、苔が付いている。
2. 石の塀（縦）：1と同じ塀が、マスの上はしから下はしまで縦に通っている。
3. 石の塀（角）：1と同じ塀が、マスのまん中で直角に曲がる（右と下へ伸びる）。
4. 崩れた塀：1と同じ横の塀の、まん中が崩れて、人型の機兵が一機通れるくらいの穴が開いている。穴の足もとに崩れた石が散らばっている。
5. 正門（2マスぶんの横長）：1と同じ塀に作られた、大きな両開きの木の門。太い石の門柱が両側にあり、古い木の扉は内側に開いたまま、蝶番が錆びている。
6. 倉庫（横長、2マスぶん）：真上から見た、細長い木造の倉庫。切妻の屋根（瓦は黒ずんだ茶色）で、屋根の棟が横に通る。古びていて、瓦がところどころ落ちて小さな穴が開いている。
7. 倉庫（縦長、3マスぶん）：6と同じ倉庫を、縦長にしたもの。屋根の棟が縦に通る。
8. 大倉庫（横長、2マスぶん）：6よりひと回り立派な、赤茶色の瓦屋根の大きな倉庫。手前（下）の壁に、大きな両開きの扉が開いていて、中は暗い。扉の脇に、赤い印の付いた樽がいくつか。
9. 木箱と樽の山：古い木箱を三、四個積み上げ、樽を二つ添えた資材の山。
```

## 2. 戦闘の背景（倉庫の敷地）

今は砦の背景（丸太の柵の砦）を使っている。合わない場合だけ描く。

```
添付の戦闘背景の絵と同じ絵柄で、ロボットの戦闘シーンの背景画を1枚描いてください。添付の絵と同じく、横長で、手前に人型の機兵が立つ平らな地面の帯があり、奥に景色が広がる構図にしてください。

場所：中世ヨーロッパ風のファンタジーの帝国の都の外れにある、三十年前に使われなくなった帝国軍の古い補給基地の敷地。
構図：手前は踏み固められた土の広場（何も置かない。ここにロボットが立つ）。奥に、石の塀と、古い木造の倉庫が何棟も並ぶ。倉庫の軒先に古い木箱や樽が積まれている。いちばん奥に、ひときわ大きな倉庫。
時間と空気：夕方。赤い夕日が倉庫の屋根を照らし、長い影が伸びる。うら寂しく、張りつめた空気。
人物、ロボット、文字は入れないでください。ビルや鉄骨、電線など近代的なものは描かないでください。
```
