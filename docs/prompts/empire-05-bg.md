# 帝国編 第5話「城館の夜」 背景の指示文

添付：`assets/bg/manor.jpg`・`assets/bg/depot_night.jpg`（会話の背景画。絵柄と、夜の色合いをそろえるため）
会話の背景画は抜かずにそのまま使う。縦長（9:16、スマートフォンの縦画面向け）。
城館の広間・司令部・格納庫は今の絵を使う。

## 1. 城館（夜）：城の外観と西門

```
添付の背景画と同じ絵柄（アニメ調の背景美術、やわらかい塗り）で、会話シーンの背景画を1枚描いてください。夜の色合いは、添付の夜の補給基地の絵に合わせてください。

場所：中世ヨーロッパ風のファンタジーの帝国の、辺境の田舎貴族の古い城館。三百年続く家だが、少し落ちぶれている。
構図：城館の西側の外から、西門を見上げる。手前は門へ続く土の道と、道の両側の草地。正面に、石造りの古い城壁と、木の扉に鉄の帯を打った大きな西門。門の上に小さな見張り台。城壁の上に、黒い大砲の影が二つ。城壁の向こうに、城館の尖った屋根と塔がそびえ、塔のてっぺんにえんじ色の地に金色の塔の紋章の旗。城壁のふもとに、城下の小さな家が数軒、窓に小さな明かり。
時間と空気：月のない暗い夜。濃い紺色の空に星。城の窓と、城壁の上のかがり火だけが暖かく光る。静かで、嵐の前のような張りつめた空気。
人物、ロボット、文字は入れないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```

## 2. 戦闘の背景：城門の前（夜）

添付：`assets/bg/battle_fort.jpg`・`assets/bg/battle_plain.jpg`（今の戦闘の背景。絵柄と構図をそろえるため）
なければ、今の砦・村の背景をゲーム側で暗くして使う。

```
添付の戦闘背景と同じ絵柄・同じ構図（横長、地平線は画面の下から1/3あたり、手前は平らな地面）で、新しい戦闘背景を1枚描いてください。

場所：中世ヨーロッパ風のファンタジーの帝国の、辺境の古い城館の西門の前。
奥：石造りの古い城壁と、閉ざされた大きな木の門。城壁の上にかがり火と、えんじ色の地に金色の塔の紋章の旗。城壁の向こうに城館の塔の影。
手前：門の前の踏み固められた土の広場。手前の地面は平らにして、何も置かない（ここにロボットが立つ）。
時間と空気：月のない夜。濃い紺色の空に星。かがり火の暖かい光が城壁を下から照らし、手前の地面は青く暗い。
人物、ロボット、文字は入れないでください。
横長（3:2）。
```
