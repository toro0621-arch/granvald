# 帝国編 第8話「夜明けの印」 ロボ（機体）の指示文

添付：`docs/ref/zekt-v2-sprites.png`（ゼクトの資料。この形式で描くと絵柄と大きさがそろう）
資料の形式（パネルの背景は明るい水色の無地）で頼む。切り抜きはこちらでするので、資料の文字やパネルはあってよい。

暁の同盟の機兵は、**共和国の量産機を、同盟の色に塗り替えたもの**（新しくデザインしてよい。ユーザー）。帝国のゼクトとはっきり見分けがつくようにする。
名前は案：共和国の量産機「エスタ」（エスタリス共和国から）。同盟の塗装のものは、ゲームの中では「暁の機兵」と呼ぶ。
3枚とも同じ機体の兵装違い。1枚目（前衛）を先に描いてもらい、2・3枚目にはそれも添付すると形がそろう。

## 1. 暁の機兵（前衛・盾）

```
添付の「ユニットグラフィック」の資料と、まったく同じ形式・同じ絵柄で、新しい機体「エスタ（暁の同盟仕様・前衛）」の資料を1枚描いてください。
形式：添付と同じ並び（頭部アップ、戦闘用の大きい絵、4方向、待機・歩行・攻撃、ユニットデータ、武器）。パネルの中の背景は添付と同じ明るい水色の一色のベタ塗り（グラデーションなし）。腕と体のすき間・脚の間など抜けている部分も同じ水色にしてください。足元の影や地面は描かないでください。

設定：南の共和国の主力量産機。帝国の量産機（添付のゼクト）とは別の国の機体なので、形をはっきり変えてください。それを帝国の中の武装組織「暁の同盟」が受け取り、自分たちの色に塗り替えて使っている。寄せ集めではなく、整備の行き届いた正規軍の機体。
形：
・ゼクトより細身で、背が少し高い。肩は丸く小さめ、胸は前に張り出した厚い装甲で、胸の両脇に排気口。
・頭は横に平たい楕円形の、つるりとした兜。顔の前面に、横一列に並んだ小さな丸いレンズが3つ（淡い緑に光る）。口や鼻のような形は付けない。
・背中に四角い背嚢（バックパック）と、そこから斜め上に伸びる細いむち形のアンテナ1本（頭には角もアンテナも付けない）。
・脚はまっすぐで、すそは広げない。足首は細く、足は前後に長い。
・左腕に、体の半分を隠す縦長の長方形の大盾。右手に銃身の短いカービン銃。
塗装：
・全身を炭のような濃い灰色に塗り替えてある。関節や装甲のふち、塗り残しのところどころに、もとの共和国軍の砂色（くすんだ黄土色）がのぞく。
・左肩と盾に、夜明けの太陽の印（地平線から半分のぞく太陽と、そこから伸びる光の線。だいだい色）。肩の印の下に、削り取られた別の紋章のあとがうっすら見える。
入れないもの：単眼、2つの目と口元のマスク状の顔、頭部のV字のアンテナ、頭の角、口元や首の動力パイプ（チューブ）、肩のとげ、腰のスカート状の装甲、背中の翼。既存のアニメの機体に似てしまうので、絶対に描かないでください。
攻撃のコマ：右を向いて、盾を前に構えたまま、盾の横からカービン銃を撃つ姿勢。銃口の火や弾の線は描かない。
ユニットデータ：HP 2600、EN 100、装甲 950、運動性 75、移動 4、地形 陸。武器：盾打ち（格闘、威力1200、射程1）、カービン銃（射撃、威力1300、射程1〜3）。
```

## 2. 暁の機兵（後衛・砲）

```
添付の「ユニットグラフィック」の資料と、まったく同じ形式・同じ絵柄で、「エスタ（暁の同盟仕様・後衛）」の資料を1枚描いてください。添付のもう1枚（前衛の資料）と同じ機体の、兵装違いです。
形式：添付と同じ並び（頭部アップ、戦闘用の大きい絵、4方向、待機・歩行・攻撃、ユニットデータ、武器）。パネルの中の背景は明るい水色の一色のベタ塗り（グラデーションなし）。腕と体のすき間・脚の間など抜けている部分も同じ水色にしてください。足元の影や地面は描かないでください。

変えないところ：前衛の資料と同じ体（細身の胴、平たい楕円の兜と横一列の3つの緑のレンズ、背嚢とむち形のアンテナ、まっすぐな脚）、同じ塗装（炭のような濃い灰色、ところどころにのぞく砂色、だいだい色の夜明けの太陽の印）。
変えるところ：
・盾は持たない。右肩の上に、背嚢から伸びる短い筒の迫撃砲を1門のせる（砲口は斜め上を向く）。
・両手で、銃身の長い小銃を持つ。
・左肩に夜明けの太陽の印。胸に予備の弾倉を入れた箱を2つ。
入れないもの：単眼、2つの目と口元のマスク状の顔、頭部のV字のアンテナ、頭の角、口元や首の動力パイプ、肩のとげ、腰のスカート状の装甲、背中の翼。
攻撃のコマ：右を向いて、片ひざをつき、肩の迫撃砲を撃つ構え。砲口の火や煙は描かない。
ユニットデータ：HP 2200、EN 110、装甲 700、運動性 70、移動 4、地形 陸。武器：小銃（射撃、威力1100、射程1〜3）、迫撃砲（射撃、威力1700、射程2〜5）。
```

```

・左腕に前衛より小さい円形の盾、右手にカービン銃、腰に片刃の軍刀。

攻撃のコマ：右を向いて、軍刀を抜いて踏み込む姿勢。斬撃の線は描かない。
ユニットデータ：HP 4200、EN 130、装甲 1000、運動性 90、移動 5、地形 陸。武器：軍刀（格闘、威力1500、射程1）、カービン銃（射撃、威力1400、射程1〜3）、一斉射撃の号令（射撃、威力2400、射程1〜4、気力110）。
```

- 荷車（同盟の荷運び）は機兵ではないので、絵はあとで考える（今の整備車両の色違いでも可）。
- 指導者「黎明」＝ルーカス・ハルトの専用機は、暁の同盟編で出すときに別に描く。
- 切り抜きは `tools/unit_sheet.py` の `SHEETS` に足して行う（パネルの位置が添付と同じなら、そのまま使える）。
