## 1. 軍務省の記録局

```
添付の背景画と同じ絵柄（アニメ調の背景美術、やわらかい塗り）で、会話シーンの背景画を1枚描いてください。

場所：中世ヨーロッパ風のファンタジーの帝国の都の、軍務省の地下にある記録局。古い書類を保管する、忘れられた部署。
構図：部屋の入り口から奥を見る。石造りの地下室で、天井は低いアーチ形。左右の壁一面に、天井まで届く木の書棚。書棚には紐でくくった書類の束と、分厚い帳簿がぎっしり詰まり、入りきらない書類が床にも塔のように積み上がっている。奥に、書類に埋もれた古い木の机が一つと、背もたれの高い椅子。机の上にランプと、インク壺と羽ペン。高いところに小さな明かり取りの窓が一つ。
時間と空気：昼だが薄暗い。窓からの細い光の筋に、ほこりが舞っている。ランプの暖かい光。かび臭く、ひっそりとした空気。
人物、ロボット、文字は入れないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```

```

時間と空気：夕方。窓から斜めに差し込む夕日と、机の上の蝋燭の灯り。静かで、仕事に追われる空気。
人物、ロボット、文字は入れないでください。

## 3. 元帥府の執務室

```

場所：中世ヨーロッパ風のファンタジーの帝国の都の、帝国軍の元帥の執務室。清廉で厳格な老将の部屋。

時間と空気：朝。窓から澄んだ光が差し込む。きびしく、ひきしまった空気。
人物、文字は入れないでください（絵の中の機兵は小さくてよい）。
縦長（9:16、スマートフォンの縦画面向け）。

## 4. 帝都の外れの兵站倉庫（夕方）

```
添付の背景画と同じ絵柄（アニメ調の背景美術、やわらかい塗り）で、会話シーンの背景画を1枚描いてください。

場所：中世ヨーロッパ風のファンタジーの帝国の都の外れにある、三十年前に使われなくなった古い軍の兵站倉庫。人型の機兵を何十機もしまえる、大きな倉庫。
構図：倉庫の前の、雑草の生えた石畳の広場から、倉庫を見上げる。石とれんがでできた大きな倉庫で、正面に機兵が出入りできるほどの巨大な両開きの鉄の扉。扉は少し開いていて、中は暗い。屋根の一部は崩れかけ、壁には蔦。倉庫のまわりに、古い木箱と錆びた鉄材の山、崩れた柵。遠くに帝都の城壁と尖塔の影。倉庫の扉の上に、かすれた帝国軍の紋章（双頭の鷲）。
時間と空気：夕方。赤く染まった空と、長く伸びる影。人けがなく、何かが潜んでいそうな不穏な空気。
人物、ロボット、文字は入れないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```
