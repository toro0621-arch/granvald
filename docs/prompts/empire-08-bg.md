# 帝国編 第8話「夜明けの印」 背景の指示文

添付：`assets/bg/gate.jpg`・`assets/bg/warehouse.jpg`（会話の背景画。帝都の街並みと絵柄をそろえるため）
会話の背景画は抜かずにそのまま使う。縦長（9:16、スマートフォンの縦画面向け）。
書記官室（第7話）と司令部は今の絵を使う。運河沿いの倉庫の夜明けは、夜の絵をゲーム側で明るくして作る（描かなくてよい）。
戦闘の背景は、今の村・砦の背景を暗くして使う（なければ）。

## 1. 帝都の下町

```
添付の背景画と同じ絵柄（アニメ調の背景美術、やわらかい塗り）で、会話シーンの背景画を1枚描いてください。添付の帝都の城門の絵と同じ都の、貧しい人々が暮らす下町です。

場所：中世ヨーロッパ風のファンタジーの帝国の都の下町。身分の低い人々が暮らす、狭く入り組んだ路地。
構図：路地の中から奥を見る。両側に、すすけた石と木組みの古い三、四階建ての家がぎっしり並び、上の階が路地に張り出していて、空は細くしか見えない。家と家のあいだに洗濯物の綱。石畳は欠けていて、水たまり。壁の一つに、だいだい色の塗料で描かれた夜明けの太陽の印（地平線から半分のぞく太陽と光の線）の落書き。奥の路地の先に、遠く宮殿の尖塔が小さく見える。木箱、樽、壊れた荷車。
時間と空気：昼。細い空から差し込む光と、路地の暗い影。貧しく、ざわついた、張りつめた空気。
人物、ロボット、文字は入れないでください（落書きは印の絵だけで、文字は書かない）。ビルや街灯、電線など近代的なものは描かないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```

## 2. 近衛の詰所

```
添付の背景画と同じ絵柄（アニメ調の背景美術、やわらかい塗り）で、会話シーンの背景画を1枚描いてください。

場所：中世ヨーロッパ風のファンタジーの帝国の都の、皇帝直属の近衛の詰所。規律正しいエリート部隊の作戦室。
構図：部屋の中を見渡す。石の壁に黒と銀の近衛の旗（銀の狼の頭の紋章）。部屋の中央に大きな木の作戦机があり、その上に帝都の街並みを描いた大きな地図が広げられ、木の駒がいくつか並び、ランプが置かれている。壁際に武器掛けと、整然と並んだ書類の棚。奥に縦長の窓があり、窓の外に夜の帝都の屋根。
時間と空気：夜。机の上のランプと壁の燭台の灯り。引き締まった、静かで整った空気。
人物、ロボット、文字は入れないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```

## 3. 運河沿いの穀物倉庫（新月の夜）

```
添付の背景画と同じ絵柄（アニメ調の背景美術、やわらかい塗り）で、会話シーンの背景画を1枚描いてください。

場所：中世ヨーロッパ風のファンタジーの帝国の都の、東の城壁の外にある運河沿いの大きな穀物倉庫。人型の機兵が何機も並べるほど広い、倉庫の前の石畳の荷揚げ場。
構図：倉庫の前の荷揚げ場から見る。右側に、石とれんがでできた大きな三階建ての穀物倉庫が並び、大きな扉の前に麦袋の山。左側に、石垣で囲まれた運河と、つながれた小舟。奥に、運河に架かる石の橋と、その向こうに城壁と帝都の尖塔の影。手前は広い石畳で、何も置かない（ここにロボットが立つ）。倉庫の軒先に、ランタンが一つだけ灯っている。
時間と空気：月のない夜。濃い紺色の空に星。運河の水面に、ランタンの小さな光が揺れて映る。暗く、静まり返った、何かが起こる前の空気。
人物、ロボット、文字は入れないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```
