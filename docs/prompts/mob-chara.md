# モブ兵士 キャラ（顔グラ）の指示文

これまで、名前のない兵士（モブ）には顔グラがなかった。戦闘中にモブが話す（攻撃のときのひとこと）と、顔の枠が空いて違和感があった（2026-11-01 ユーザーの指摘）。
1人の顔を、同じ役の全員で使い回す（例：男爵家の騎士は全員同じ顔）。

> できあがり：`docs/ref/mob-faces-a.png` → `assets/faces/bandit.png`・`baron_knight.png`・`soldier.png`・`hitman.png`、`docs/ref/mob-faces-b.png` → `dawn_soldier.png`・`dawn_gunner.png`・`official.png`・`hagen.png`（全員使う。`python3 tools/faces_all.py`）。同盟の後衛（迫撃砲の機兵）のパイロット名は「同盟の砲手」にした。

添付：`docs/ref/empire-08-faces.png`（第8話の顔グラの資料。この形式で描くと絵柄がそろう。名前の札がパネルの下にあるので、頭が欠けずに切れる）
切り抜きはこちらでするので、資料の文字やパネルはあってよい。

使う場所（案）：
- 1枚目：盗賊兵（第1・2話）、男爵家の騎士（第3〜5話。城壁の砲兵も兼ねる）、帝国の一般兵（第6話の護送兵、第7話の兵站局の兵、若い伝令も兼ねる）、刺客（第6話）
- 2枚目：同盟兵（第8話から）、同盟の砲手（第8話から。同盟兵の2人目）、宮廷の役人（兵站局の役人・儀典官）、ハーゲンの部族兵（第9話から）

## 1. 帝国の側のモブ（4人分・1枚の資料）

```
添付の「キャラクター顔グラフィック」の資料と、まったく同じ形式・同じ絵柄（同じ画家が描いたように）で、新しい4人分の資料を1枚描いてください。
形式：上に題名の帯、その下に4人分の縦長のパネルを横に並べ、各パネルの下に名前の札と短い説明文（添付と同じく、名前の札はパネルの下）。パネルの中は胸から上の人物画で、背景は明るい灰色の無地（グラデーションなし）。人物の頭の上には少し余白をあけてください。
絵柄：添付と同じアニメ調。細めの線、陰影のある落ち着いた塗り、汚れや傷の描き込み。太い線のマンガ風やベタ塗りにしない。
世界観：中世ヨーロッパ風のファンタジーの帝国。服は軍服や庶民の服で、現代の服にしない。
名前のない兵士たちなので、目立ちすぎない、どこにでもいそうな顔にしてください。

1人目「盗賊兵」：30代の男性。辺境の盗賊団の、機兵乗りの下っ端。無精ひげ、日焼けした顔、ぼさぼさの茶色の髪をバンダナでまとめている。継ぎはぎの革の上着。表情は粗野で、にやりと笑っている。
2人目「男爵家の騎士」：20代後半の男性。辺境の男爵家に仕える騎士。短く刈った金茶色の髪、生まじめな顔。えんじ色の騎士の上着に、銀の胸当て。胸に男爵家の紋章。表情は引き締まっていて、少し気負っている。
3人目「帝国兵」：20代前半の男性。帝国軍の一般の機兵乗り。短い黒髪、どこにでもいそうな顔。濃い灰色の帝国軍の軍服（赤の差し色、詰め襟）。表情はまじめで、少し緊張している。
4人目「刺客」：30代の男性。金で雇われた傭兵崩れの機兵乗り。顔の下半分を黒い布で覆い、見えているのは冷たい目元だけ。黒く塗った革の帽子と、紋章のない黒い革の上着。表情は冷めていて、感情がない。
```

## 2. 同盟と、そのほかのモブ（4人分・1枚の資料）

```
添付の「キャラクター顔グラフィック」の資料と、まったく同じ形式・同じ絵柄（同じ画家が描いたように）で、新しい4人分の資料を1枚描いてください。
形式：上に題名の帯、その下に4人分の縦長のパネルを横に並べ、各パネルの下に名前の札と短い説明文（添付と同じく、名前の札はパネルの下）。パネルの中は胸から上の人物画で、背景は明るい灰色の無地（グラデーションなし）。人物の頭の上には少し余白をあけてください。
絵柄：添付と同じアニメ調。細めの線、陰影のある落ち着いた塗り、汚れや傷の描き込み。太い線のマンガ風やベタ塗りにしない。
世界観：中世ヨーロッパ風のファンタジーの帝国。服は軍服や庶民の服で、現代の服にしない。
名前のない人たちなので、目立ちすぎない、どこにでもいそうな顔にしてください。

1人目「同盟兵」：20代前半の男性。帝国の中で身分制度と戦う武装組織「暁の同盟」の兵士。下町の平民の若者。炭のような濃い灰色の作業着の上着に、左腕にだいだい色の夜明けの太陽の印（地平線から半分のぞく太陽と光の線）の腕章。顔の下半分を、くすんだ灰色の布で覆っていて、見えているのは目元と、短い茶色の髪だけ。表情は真剣で、規律正しい兵士の目。
2人目「同盟の砲手」：20代半ばの女性。同じ「暁の同盟」の機兵の砲手。黒髪を後ろで短く一つにまとめ、額に古い飛行用のゴーグルを上げている。炭のような濃い灰色の作業着に、だいだい色の夜明けの太陽の印の腕章。頬にすす。表情は落ち着いていて、きりっとしている。
3人目「宮廷の役人」：40代の男性。帝国の宮廷や役所で働く貴族出の役人。なでつけた灰色まじりの髪、細い口ひげ。深い紺色の文官の上着に、白い襟。表情は尊大で、人を見下すように少しあごを上げている。
4人目「ハーゲンの部族兵」：30代の男性。帝国の北東の草原に住む騎馬民族の戦士。日に焼けた浅黒い肌、長い黒髪を何本もの細い三つ編みにしている。毛皮のふちの付いた厚い革の上着と、色とりどりの糸で刺繍した帯。頬に部族の青い入れ墨の線。表情は鋭く、ふてぶてしい。
```
