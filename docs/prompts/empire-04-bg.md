## 1. 第七補給基地

```
添付の背景画と同じ絵柄（アニメ調の背景美術、やわらかい塗り）で、会話シーンの背景画を1枚描いてください。

場所：中世ヨーロッパ風のファンタジーの帝国の、辺境の街道沿いにある小さな軍の補給基地。
内容：丸太の柵で囲まれた敷地。木と石でできた倉庫が二つ三つ並び、扉の前に木箱や樽、麻袋が積み上げてある。荷車と、つながれた馬。屋根だけの大きな木造の小屋（ロボットの整備場）が奥にあり、中は暗くて見えない。見張りの物見やぐらが一つ。柵の外には街道と、なだらかな草原、遠くに森。基地の隅に、炊き出しの大鍋と、煙の上がるかまど。
雰囲気：前線から遠い、のんびりした後方の基地。きちんと片付いているが、地味で寂しい。
時間と空気：初夏の昼すぎ。晴れていて、空が広い。
人物、ロボット、文字は入れないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```

## 2. 夜の街道（ヨハンの隊の行軍）

台本の「西の街道（夜）」の場面。補給基地の絵を暗くした版（`depot_night.jpg`）だと、まだ着いていない基地が映ってしまうので、別に頼む。行軍や移動の場面にも使い回せる。

```
添付の背景画と同じ絵柄（アニメ調の背景美術、やわらかい塗り）で、会話シーンの背景画を1枚描いてください。

場所：中世ヨーロッパ風のファンタジーの帝国の、辺境の田舎の街道。
構図：手前から奥へ、土の街道がゆるやかに曲がりながら続いている。道の両側は草原と、ところどころに黒い森のかたまり。奥はなだらかな丘。道ばたに、古い木の道しるべが一本。遠くの丘の向こうに、小さな明かりがいくつか見える（目指す補給基地の灯）。
時間と空気：月の明るい夜。濃い青の夜空に月と星。月明かりで道と草原がうっすら青白く照らされ、森は黒い影になっている。静かで、これから何かが起きそうな張りつめた空気。
人物、ロボット、文字は入れないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```
