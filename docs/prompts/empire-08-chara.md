## 顔グラ4人分（1枚の資料）

```
添付の「キャラクター顔グラフィック」の資料と、まったく同じ形式・同じ絵柄（同じ画家が描いたように）で、新しい4人分の資料を1枚描いてください。
形式：上に題名の帯、その下に4人分の縦長のパネルを横に並べ、各パネルの上に名前の札、下に短い説明文。パネルの中は胸から上の人物画で、背景は明るい灰色の無地。人物の頭の上には少し余白をあけ、名前の札に頭や髪が重ならないようにしてください。
絵柄：添付と同じアニメ調。細めの線、陰影のある落ち着いた塗り、汚れや傷の描き込み。太い線のマンガ風やベタ塗りにしない。
世界観：中世ヨーロッパ風のファンタジーの帝国。服は軍服や庶民の服で、現代の服にしない。

1人目「同盟の隊長」：30代の男性。帝国の中で身分制度と戦う武装組織「暁の同盟」の機兵部隊の隊長。規律正しく、冷静な指揮官。名前も顔も明かさない。目から下を、くすんだ鉄色のなめらかな半仮面で覆い、頭には濃い灰色のフードをかぶっている。見えているのは、落ち着いた鋭い灰色の目と、フードからのぞく黒髪の前髪だけ。炭のような濃い灰色の、詰め襟の軍用の外套（どこの国の軍服でもない、記章をはがした跡のある服）。左の胸に、だいだい色の夜明けの太陽の印（地平線から半分のぞく太陽と光の線）の刺繍。表情は感情を見せず、静かで、まっすぐ相手を見ている。ゴーグルや飛行帽は付けない。
2人目「エルザ」：27歳の女性。帝都の近衛の騎士で、近衛の少佐の副官。少佐とは幼なじみ。落ち着いていて、面倒見がよい。赤みがかった栗色の髪を後ろで一つにきっちりまとめ、前髪は短め。やさしい茶色の目。黒の詰め襟の近衛の軍服に、銀の肩章と銀の飾り緒（添付の資料の近衛の軍服と同じ）。表情は穏やかで、少し困ったような微笑み。
3人目「ハンス」：18歳の男性。帝都の下町生まれの若者で、「暁の同盟」の新米の兵士。痩せていて、そばかす。ぼさぼさの麦わら色の短い髪。大きな青い目。炭のような濃い灰色の粗い作業着の上着に、左腕にだいだい色の夜明けの太陽の印の腕章。首に古い手ぬぐい。表情は緊張していて、強がっているが少しおびえている。
4人目「戦友の母」：50代の女性。帝都の下町に住む、貧しい暮らしの母親。息子を兵隊で亡くしている。白髪まじりの茶色の髪をひっつめにして、頭に色あせた布をかぶっている。目じりにしわ。色あせた茶色の粗い服に、すり切れた毛糸の肩掛け。表情はやさしいが、疲れていて、どこか寂しげ。
```
