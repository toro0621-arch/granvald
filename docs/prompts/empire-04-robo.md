# 帝国編 第4話「後方の狙撃手」 ロボ（機体）の指示文

添付：`docs/ref/zekt-v2-sprites.png`（ゼクトの資料。この形式で描くと絵柄と大きさがそろう）
資料の形式（パネルの背景は明るい水色の無地）で頼む。切り抜きはこちらでするので、資料の文字やパネルはあってよい。
ヨハン機は、描かずにゼクトの絵に色を重ねるだけでも済む（男爵家の騎士と見分けがつきにくくなるので、できれば描く）。
男爵家の騎士の機体は、第3話と同じ（ゼクトの絵にえんじ色を重ねる）。

## 1. ニーナの狙撃機「ゼクト・シュッツェ」（名前は案）

```
添付の「ユニットグラフィック」の資料と、まったく同じ形式・同じ絵柄で、兵装違いの機体「ゼクト・シュッツェ」の資料を1枚描いてください。
形式：添付と同じ並び（頭部アップ、戦闘用の大きい絵、4方向、待機・歩行・攻撃、ユニットデータ、武器）。パネルの中の背景は添付と同じ明るい水色の無地。足元の影や地面は描かないでください。

機体は、添付のゼクトの体をそのまま使い、武装と装備だけを変えます。頭の形と単眼は変えないでください。
変えないところ：つばのある鉄兜の形の丸い頭、固定式の赤い単眼、青灰色の装甲、胴と脚の形。
変えるところ：
・両手で持つ、機体の背丈ほどもある長い狙撃銃。銃身の先に折りたたみ式の二脚（支え脚）、銃の上に細長い照準器。
・頭の右側に、鉄兜のつばの下から前へ伸びる、筒形の照準器（望遠鏡のような形）を1本取り付ける。単眼とは別の部品で、単眼の前にはかぶせない。
・肩から背中にかけて、緑と茶色のまだらの、すり切れた迷彩の布（外套）をかぶせる。
・左の盾は外し、腰に短い拳銃。左肩に白い補給部隊の印。
入れないもの：口元や首の動力パイプ（チューブ）、肩のとげ、腰のスカート状の装甲、単眼が動くためのレール、頭部のV字のアンテナ。既存のアニメの機体に似てしまうので、絶対に描かないでください。
攻撃のコマ：右を向いて、片ひざをついて狙撃銃を構える姿勢。銃口の火や弾の線は描かない。
ユニットデータ：HP 2200、EN 100、装甲 750、運動性 85、移動 4、地形 陸。武器：拳銃（射撃、威力900、射程1〜2）、狙撃銃（射撃、威力1800、射程3〜6）、一点狙撃（射撃、威力2700、射程3〜6）。
```

## 2. ヨハンの機体「ゼクト・エーレ」（名前は案）

```
添付の「ユニットグラフィック」の資料と、まったく同じ形式・同じ絵柄で、兵装違いの機体「ゼクト・エーレ」の資料を1枚描いてください。
形式：添付と同じ並び（頭部アップ、戦闘用の大きい絵、4方向、待機・歩行・攻撃、ユニットデータ、武器）。パネルの中の背景は添付と同じ明るい水色の無地。足元の影や地面は描かないでください。

設定：辺境の男爵家の分家の若い貴族の機体。中身は横流しの量産機だが、見栄を張って飾り立ててある。貧乏な家なので、飾りはどこか安っぽい。
機体は、添付のゼクトの体をそのまま使い、塗装と飾りだけを変えます。頭の形と単眼は変えないでください。
変えないところ：つばのある鉄兜の形の丸い頭、固定式の赤い単眼、胴と脚の形。
変えるところ：
・全身をえんじ色に塗り、装甲のふちに金色の縁取り（ところどころ塗りがはげている）。
・左腕の大きな盾に、大きく描いた家紋（えんじ色の地に、金色の塔の紋章）。右肩にも同じ家紋。肩の家紋だけ、描き直したばかりで色があざやか。
・背中に短いえんじ色のマント（すそが少しほつれている）。
・右手に、斧の代わりに細身の長剣（儀礼用のような、つばに飾りのある剣）。
入れないもの：頭の羽根飾り、頭部のV字のアンテナ、口元や首の動力パイプ、肩のとげ、腰のスカート状の装甲、背中の翼。既存のアニメの機体に似せないでください。
攻撃のコマ：右を向いて、長剣を大きく振りかぶる構え。斬撃の線は描かない。
ユニットデータ：HP 3600、EN 110、装甲 1000、運動性 80、移動 5、地形 陸。武器：長剣（格闘、威力1600、射程1）、ライフル（射撃、威力1400、射程1〜3）、名誉の突撃（格闘、威力2600、射程1）。
```
