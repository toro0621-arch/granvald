## 顔グラ1人分（1枚の資料）

```
添付の「キャラクター顔グラフィック」の資料と、まったく同じ形式・同じ絵柄（同じ画家が描いたように）で、新しい1人分の資料を1枚描いてください。
形式：上に題名の帯、その下に縦長のパネルを1つ、パネルの上に名前の札、下に短い説明文。パネルの中は胸から上の人物画で、背景は明るい灰色の無地。
絵柄：添付と同じアニメ調。細めの線、陰影のある落ち着いた塗り、汚れや傷の描き込み。太い線のマンガ風やベタ塗りにしない。
世界観：中世ヨーロッパ風のファンタジーの帝国。服は軍服で、現代の服にしない。

人物「ヴォルフ」：27歳の男性。帝国の名門貴族の出で、帝都の近衛の少佐。皇帝への忠誠は本物で、家柄より実力を重んじるため、貴族仲間から浮いている。主人公のライバル。
見た目：背が高く細身。黒に近い濃い灰色の髪を、きっちり後ろへなでつけ、前髪が一筋だけ額に落ちている。鋭い切れ長の目で、瞳は冷たい氷のような薄い青。整った顔立ちだが、口元は固く結ばれている。
服：黒の詰め襟の近衛の軍服に、銀の飾り緒と銀の肩章。胸に、銀色の狼の頭の家紋の徽章。白い手袋。
表情：冷たく、人を値踏みするような目つき。見下しているが、卑しさはなく、まっすぐな厳しさがある。
金髪にしない。眼帯や片眼鏡は付けない。
```
