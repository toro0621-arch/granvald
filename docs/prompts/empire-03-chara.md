## 顔グラ4人分（1枚の資料）

```
添付の「キャラクター顔グラフィック」の資料と、まったく同じ形式・同じ絵柄（同じ画家が描いたように）で、新しい4人分の資料を1枚描いてください。
形式：上に題名の帯、その下に4人分の縦長のパネルを横に並べ、各パネルの上に名前の札、下に短い説明文。パネルの中は胸から上の人物画で、背景は明るい灰色の無地。
絵柄：添付と同じアニメ調。細めの線、陰影のある落ち着いた塗り、汚れや傷の描き込み。太い線のマンガ風やベタ塗りにしない。
世界観：中世ヨーロッパ風のファンタジーの帝国。服は軍服や貴族の服で、現代の服にしない。

1人目「ブルクハルト男爵」：40代後半の男性。辺境の田舎貴族。太り気味で二重あご、手入れした口ひげを左右にはね上げている。古くさいが派手な貴族服（えんじ色の上着に金の刺しゅう、レースの襟）。家紋の入った大きな指輪。見栄っ張りで怒りっぽく、ふんぞり返った表情。
2人目「ディートリヒ」：50代後半の男性。男爵家の騎士団長。平民の生まれで、腕を見込まれて騎士に取り立てられた。短く刈った白髪まじりの灰色の髪、日焼けした顔に深いしわと古い刀傷。がっしりした体。使い込んだ鈍い鉄色の胸当ての上に、えんじ色の男爵家の外套。厳しいが、目の奥に深い悲しみと優しさがある表情。
3人目「ヨハン」：20歳ほどの男性。男爵の親戚の下級貴族（分家の貧乏貴族）。細身で、明るい金髪を丁寧になでつけている。貴族らしく見せようとした服だが、よく見ると古着で、袖口がすり切れている。人を見下すような薄笑いの中に、焦りと劣等感がにじむ表情。
4人目「農民兵」：20歳前後の男性。男爵に無理やり兵にされた村の若者。日焼けした素朴な顔、短いぼさぼさの茶色の髪。麻の野良着の上に、サイズの合わない古い革の胴当て。おびえて、今にも泣き出しそうな表情。
```
