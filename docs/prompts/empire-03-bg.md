## 1. 男爵の城館の広間

```
添付の背景画と同じ絵柄（アニメ調の背景美術、やわらかい塗り）で、会話シーンの背景画を1枚描いてください。

場所：中世ヨーロッパ風のファンタジーの帝国の、辺境の田舎貴族の城館の広間。三百年続く古い家だが、今は少し落ちぶれている。
内容：石造りの広間。正面の奥に、背もたれの高い当主の椅子。壁には男爵家の家紋（えんじ色の地に、金色の塔の紋章）の旗と、色あせたタペストリー。長い木の食卓、燭台のろうそく、壁の鹿の角の飾り。見栄を張った調度品だが、よく見ると金の塗りがはげていたり、絨毯がすり切れていたりする。
時間と空気：夜。ろうそくの暖かい光と、部屋の隅の暗がり。重苦しい雰囲気。
人物、ロボット、文字は入れないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```

## 2. グラウ川の渡し

```
添付の背景画と同じ絵柄（アニメ調の背景美術、やわらかい塗り）で、会話シーンの背景画を1枚描いてください。

場所：中世ヨーロッパ風のファンタジーの帝国の、辺境の街道にある川の渡し場。
構図：手前の岸から、川の向こう岸を見る。川幅は広いが、渡し場のところだけ浅瀬になっていて、水面から目印の木の杭が点々と並んでいる。手前の岸には木の船着き場と、つながれた渡し舟、岸辺の柳。
向こう岸：丸太と荷車を積み上げたバリケードで街道がふさがれ、えんじ色の地に金色の塔の紋章の旗が何本も立っている。その奥に、小さな村の屋根と、遠くの丘。
時間と空気：初夏の朝。晴れているが、どこか張りつめた空気。
人物、ロボット、文字は入れないでください。
縦長（9:16、スマートフォンの縦画面向け）。
```
