添付：`docs/ref/empire-03-faces.png`（第3話の顔グラの資料。この形式で描くと絵柄がそろう）
切り抜きはこちらでするので、資料の文字やパネルはあってよい。

## 顔グラ2人分（1枚の資料）

```
添付の「キャラクター顔グラフィック」の資料と、まったく同じ形式・同じ絵柄（同じ画家が描いたように）で、新しい2人分の資料を1枚描いてください。
形式：上に題名の帯、その下に2人分の縦長のパネルを横に並べ、各パネルの上に名前の札、下に短い説明文。パネルの中は胸から上の人物画で、背景は明るい灰色の無地。
絵柄：添付と同じアニメ調。細めの線、陰影のある落ち着いた塗り、汚れや傷の描き込み。太い線のマンガ風やベタ塗りにしない。
世界観：中世ヨーロッパ風のファンタジーの帝国。服は軍服で、現代の服にしない。

1人目「ニーナ」：19歳の女性。帝国軍の少尉で、機兵の狙撃手。平民の生まれで、士官学校を首席で出たのに、後方の補給基地に回されている。肩までの長さの黒に近い濃い茶色の髪を、後ろで短く一つに結んでいる。前髪は目にかからない長さ。切れ長の灰色の目。小柄で細身。帝国軍の青灰色の軍服（詰め襟の上着）の上に、使い込んだ革の手袋。首に、照準器のゴーグルを下げている。無口で落ち着いた、少し冷めた表情。口元にかすかな皮肉の笑み。
2人目「補給兵」：50代の男性。辺境の補給基地の古参の兵。ずんぐりした体、丸い顔に無精ひげ、薄くなった白髪まじりの髪。くたびれた青灰色の作業服に、袖をまくった腕、首に手ぬぐい。人のいい、少し心配そうな表情。
```
