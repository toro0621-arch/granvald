# 帝国編 第3話「末席の男爵」 ロボ（機体）の指示文

添付：`docs/ref/zekt-v2-sprites.png`（ゼクトの資料。この形式で描くと絵柄と大きさがそろう）
資料の形式（パネルの背景は明るい水色の無地）で頼む。切り抜きはこちらでするので、資料の文字やパネルはあってよい。
男爵家の騎士の機体は横流しのゼクトなので、新しく描かない（ゼクトの絵に男爵家の色を重ねる）。

## 1. ゼクト・ランス（レオの機体）

```
添付の「ユニットグラフィック」の資料と、まったく同じ形式・同じ絵柄で、兵装違いの機体「ゼクト・ランス」の資料を1枚描いてください。
形式：添付と同じ並び（頭部アップ、戦闘用の大きい絵、4方向、待機・歩行・攻撃、ユニットデータ、武器）。パネルの中の背景は添付と同じ明るい水色の無地。足元の影や地面は描かないでください。

機体は、添付のゼクトの体をそのまま使い、武装と装甲だけを変えます。頭の形と単眼は変えないでください。
変えないところ：つばのある鉄兜の形の丸い頭、固定式の赤い単眼、青灰色の装甲、胴と脚の形。
変えるところ：右手に長い突撃槍（円すい形の大きな槍。持ち手に丸い鍔）。左腕の大きな盾の代わりに、小さく厚い増加装甲の盾。両肩と胸に、追加の装甲板をボルトで留める。左肩に黄色の斜めの線が1本（乗り手の印）。
入れないもの：口元や首の動力パイプ（チューブ）、肩のとげ、腰のスカート状の装甲、単眼が動くためのレール。既存のアニメの機体に似てしまうので、絶対に描かないでください。
攻撃のコマ：右を向いて、槍を前に突き出して突進する構え。突進の線や光のエフェクトは描かない。
ユニットデータ：HP 2600、EN 100、装甲 950、運動性 85、移動 5、地形 陸。武器：突撃槍（格闘、威力1500、射程1）、ライフル（射撃、威力1300、射程1〜3）、ランスチャージ（格闘、威力2600、射程1）。
```

## 2. ディートリヒの機体「アイゼンヴァハト」（名前は案）

```
添付の「ユニットグラフィック」の資料と、まったく同じ形式・同じ絵柄で、新しい機体「アイゼンヴァハト」の資料を1枚描いてください。
形式：添付と同じ並び（頭部アップ、戦闘用の大きい絵、4方向、待機・歩行・攻撃、ユニットデータ、武器）。パネルの中の背景は添付と同じ明るい水色の無地。足元の影や地面は描かないでください。

設定：辺境の男爵家の騎士団長の機体。今の量産機より一世代古い騎士用の機体を、先代の男爵から賜り、何十年も手入れしながら使い続けている。古いが、よく磨かれていて堂々としている。
形：量産機より少し背が高く、がっしりした体。丸みのある古風な厚い装甲で、鋲（リベット）がたくさん打たれている。腰から膝まで、男爵家の家紋（えんじ色の地に、金色の塔の紋章）を描いた布の陣羽織（タバード）を垂らす。
頭：首の後ろが長く伸びた古い型の鉄兜の形。顔の正面に横一本の細いスリットがあり、中が琥珀色に光る（単眼にしない。T字のスリットにしない。羽根飾りは付けない）。
武器：両手で持つ長い斧槍（ハルバード。槍の穂先と斧の刃が付いた長柄の武器）。左腕に丸い小盾。
配色：くすんだ青銅色と、暗い緑の装甲。陣羽織はえんじ色と金。
入れないもの：頭部のV字のアンテナ、二つ目にマスク状の口元の顔、背中の翼。既存のアニメの機体に似せないでください。
攻撃のコマ：右を向いて、斧槍を大きく振り下ろす構え。斬撃の線は描かない。
ユニットデータ：HP 5200、EN 140、装甲 1300、運動性 80、移動 4、地形 陸。武器：斧槍（格闘、威力2000、射程1）、マスケット砲（射撃、威力1400、射程1〜3）、鉄壁の構え（格闘、威力2800、射程1）。
```
