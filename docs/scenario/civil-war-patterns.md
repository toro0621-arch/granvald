# 帝国編 後半「内戦編」 ざっとした流れ 3パターン（案）

2026-11-02。暁の同盟編（第9〜12話）の結び「皇帝が倒れた」から始まる内戦編の、たたき台。
ユーザーが挙げた中世の10の内戦を参考に、3つの違う形を考えた。どれか一つを選ぶか、混ぜて使う。
名前・細かい設定はすべて案。前提は `STORY.md`（内戦の三本柱、北方、内戦のあいだ共和国が攻めてこない理由）。

## パターンA「天秤の冠」 ― 一進一退と、妥協の和約

**参考**：イングランド無政府時代（女の跡継ぎと男のいとこの争い、両方の大将が捕まって交換される、最後は「今の王が王のまま、次は相手の子」の和約）、第一次バロン戦争（王の力をしばる約束の文書。王の死で戦が終わり、文書を出し直して貴族が戻る）、第二次バロン戦争（改革派の大将が勝って王を捕らえるが、逃げた王子に討たれる。考えだけが残る）。

**芯**：どちらも勝ちきれない。勝ったほうが傲慢になると、味方が離れる。最後は剣ではなく「約束の文書」で終わる。

**流れ（8〜10話）**
1. **序盤（3話）**：皇帝が倒れ、遺言の解釈で宮廷が二つに割れる（皇帝は生前、貴族たちに皇女への忠誠を誓わせていたが、ユリウスの側は「病の床で言わされた」と言う）。ユリウスの側が先に帝都を押さえ、即位の儀を急ぐ。皇女は北へ逃れ、アイヒの北方軍に迎えられる。
2. **中盤（3〜4話）**：一進一退。
   - 皇女の側が大勝して、ユリウス本人を捕らえる（第二次バロン戦争の、王を捕らえた戦いのように）。
   - 勝った皇女の側の貴族が傲慢になり、帝都の民と中立の貴族が離れる（無政府時代のマティルダが、ロンドンで嫌われて追い出された話）。
   - 逆にシュタールの反撃で、アイヒ（またはエルンスト）が捕らえられる。
   - 捕虜どうしの交換。ここでヴォルフは、大切な人（エルザの案）を失う。
3. **終盤（2〜3話）**：
   - 長引く戦で、帝国の村々が荒れていく。共和国の強硬派が国境で動き始める。
   - シュタール元帥が戦場で倒れる（第二次バロン戦争の、改革派の大将の最期の型を、敵の総大将に当てる案）。
   - 両陣営の残った者たちが、聖ルミナ教国の仲立ちで和約を結ぶ。

**結末（案）**：
- 皇女が女帝になる。
- その代わり、皇帝の力をしばる「帝国憲章」を結ぶ（貴族会議の権利を残しつつ、平民の代表も会議に加える。改革の中身はぼかす）。
- ユリウスは次の帝位の継承者として貴族会議の議長になる（無政府時代の和約の「次は相手の側」の型）。
- エルンストは改革の約束を文書にして守らせる役。

**向いているところ**：
- 両方の言い分に筋が通っている今の設定に、いちばん素直に合う。
- 誰も完全には勝たないので、「改革は曖昧なまま終わってよい」とも合う。
- 捕虜の交換、裏切りと寝返りなど、毎話の戦闘の理由を作りやすい。

**気になるところ**：
- 決着がすっきりしない。
- ラストバトルの相手が決めにくい（シュタールかヴォルフか）。

## パターンB「眠る皇帝の宮廷」 ― 宮廷の派閥争いと、外の敵

**参考**：フランスの二派閥の内戦（王が心を病み、王の弟といとこの派閥が宮廷を奪い合う。両派閥の長が次々に暗殺される。イングランドが付け込んで大勝し、最後は片方の派閥が敵と手を切って和解する）、東ローマ帝国の内戦（幼い皇帝の摂政と将軍の争い。両方が外国の傭兵を呼び込み、国そのものが弱る。町の民が自分たちで町を治める）、ドイツ王位争い（二人の王が同時に選ばれ、外国がそれぞれを後押しする。片方の王が、私怨で暗殺されて急に終わる）。

**芯**：皇帝は死んでいない。眠ったまま目を覚まさない。だから「誰が皇帝の代わりに国を動かすか」の争いになる。敵は暗殺と外国。

**流れ（8〜10話）**
1. **序盤（2〜3話）**：皇帝は倒れたが、生きている（目を覚まさない）。
   - 誰が摂政になるかで、皇女の側とユリウスの側が宮廷で争う。
   - 宰相ヴェルナが両方の間で糸を引く。
   - 第一の暗殺として、総帥ザルグが殺される。犯人は分からないが、ユリウスの側は皇女の側を疑う。ここから剣の戦になる。
2. **中盤（3〜4話）**：
   - ユリウスの側は兵が足りず、ハーゲン族長国の騎馬部族を傭兵に雇う（東ローマが外国の傭兵を呼んだ型）。北の村々が荒らされ、アイヒが激怒する。
   - 皇女の側には、暁の同盟の残党と北の村の民が自分たちで加わる（東ローマで町の民が立ち上がった型。第12話のハンスたち）。
   - 両方の陣営に、外国の手が入る。
3. **終盤（2〜3話）**：
   - 第二の暗殺として、宰相ヴェルナが和解の席で殺される（フランスの、橋の上の会談で派閥の長が殺された話の型）。
   - その混乱に付け込んで、共和国の強硬派が国境を越える。
   - 南の本軍を握るシュタールは、ユリウスに「共和国と組めば帝位をやる」と持ちかける共和国の誘いを、断る（フランスで、片方の派閥が外の敵と手を切った型）。
   - 両陣営が手を結んで、共和国軍を国境で止める。
   - ここで共和国編の主人公と初めてぶつかる（案）。

**結末（案）**：
- 皇帝が一度だけ目を覚まし、皇女を跡継ぎに定めて息を引き取る。
- ユリウスは皇女に剣を捧げる。
- 戦場で出会った共和国の主人公と、停戦の話が始まる（終戦協定への橋）。

**向いているところ**：
- 第12話の「皇帝が倒れた」に、いちばん自然につながる（倒れた＝死んだ、ではない）。
- ルーカスの遺言「共和国は帝国が割れるのを待っている」を、まっすぐ回収できる。
- 共和国編へのつなぎがいちばん強い。
- 暗殺の謎（誰がザルグを殺したか）で、話を引っぱれる。

**気になるところ**：
- 帝国の中の敵（ユリウス）と最後に手を組むので、ヴォルフとの決着の付け方が難しい。案：ヴォルフだけは手を組まず、執念でエルンストに挑んで死ぬ。
- 暗殺が多いと話が暗くなる。

## パターンC「庶子の旗」 ― 明かされる血筋と、結ばれる二つの家

**参考**：カスティーリャ内戦（王と、その腹違いの庶子の兄の争い。両方に外国の名将が付く。最後は天幕の中で、兄弟がつかみ合って兄が弟を討つ）、薔薇戦争（二つの家の争いで王冠が何度も行き来する。陣営を何度も替える「王を作る男」が出る。最後は、庶子の血筋から出た傍流の男が勝ち、敵の家の娘と結婚して二つの家を一つにする）、フス戦争（民の運動が戦になり、民の側が穏健派と過激派に割れて、最後は穏健派が過激派を討つ）、ノルウェー内戦（長く続き、貧しい者たちの軍が大きくなって、最後は王になる）。

**芯**：エルンストの出生（皇帝の庶子）が、内戦の真ん中で明かされる。エルンスト自身が「旗」にされてしまう。

**流れ（10〜12話）**
1. **序盤（3話）**：パターンAの序盤と同じ（皇女が北へ逃れる）。
   - 皇女の側は数で負けていて、追いつめられる。
2. **中盤（4話）**：
   - 宰相ヴェルナが、エルンストが皇帝の庶子だという証拠を世に出す。皇女の側を割るための一手。
   - 平民の兵と北の民の一部が「平民の母を持つ皇子」に熱狂し、勝手にエルンストを帝位に担ぎ始める（ノルウェー内戦の、貧しい者たちの軍の型）。
   - 皇女の側が、皇女派とエルンスト派に割れかける。
   - ヴェルナは、ユリウスの側と皇女の側を何度も行き来する「王を作る男」になる（薔薇戦争の型）。
3. **終盤（3〜4話）**：
   - エルンストは担がれることを拒む。自分を担ぐ過激な一派を、自分の手で止める（フス戦争で穏健派が過激派を討った型。暁の同盟のラザルの話と重なる）。
   - ヴォルフとの最後の決闘になる。ヴォルフは、エルンストが皇帝の子だと知って執念を燃やし、死ぬ。
   - ユリウスと皇女は戦場で向き合う。

**結末（案）**：
- 皇女とユリウスが結婚して、二つの家を一つにする（薔薇戦争の終わりの型）。
- 女帝の前例のなさと、男系の筋が同時に片づく。
- エルンストは皇族に戻らず、名もない母の墓に名を刻む（STORY.md の最後の場面の案）。
- 改革は、二人の皇帝と議会に託される。

**向いているところ**：
- エルンストの出生と皇帝の密命という、いちばん大きな謎を内戦の真ん中に置ける。主人公の物語としていちばん強い。
- 平民の兵が多い大隊（レオ、クラーラ、ニーナ）の気持ちが揺れる場面を作れる。

**気になるところ**：
- 「庶子が帝位に担がれる」は、主人公を王位争いの当事者にするので、今までの「現場の有能な中級将校」という立ち位置から離れる。
- 話数がいちばん多くなる。
- 結婚の結末は、ユリウスと皇女の関係をそれまでに丁寧に描く必要がある。

## 3パターンの比べ

| | A 天秤の冠 | B 眠る皇帝の宮廷 | C 庶子の旗 |
|---|---|---|---|
| 主な参考 | 無政府時代・バロン戦争 | フランスの派閥争い・東ローマ・ドイツ王位争い | カスティーリャ・薔薇戦争・フス戦争 |
| 皇帝 | 倒れて死ぬ | 眠ったまま生きている | 倒れて死ぬ |
| 敵の中心 | シュタール元帥 | 暗殺者と共和国 | ヴェルナ（王を作る男）とヴォルフ |
| エルンストの出生 | 明かさなくてよい | 明かさなくてよい（最後に皇帝の口から、でもよい） | 中盤で明かす（話の芯） |
| 共和国 | 終盤に影だけ | 終盤に国境を越える（共和国編とつながる） | 影だけ |
| 結末 | 女帝と、皇帝の力をしばる憲章 | 帝国が一つにまとまり、共和国と停戦へ | 皇女とユリウスの結婚 |
| 話数（目安） | 8〜10話 | 8〜10話 | 10〜12話 |

**混ぜるなら（案）**：Bの「眠る皇帝」と「暗殺」で始め、Aの「一進一退と捕虜の交換」を中盤に置き、Bの「共和国が国境を越えて、両陣営が手を結ぶ」で終わる。エルンストの出生は、最後に目を覚ました皇帝の口から、エルンストにだけ明かす（世には出さない）。
