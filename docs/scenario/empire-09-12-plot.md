- **同盟は、外からではなく、内側から崩れる。** おきてを破る一派が出て、後ろ盾の共和国にも見捨てられ、最後は指導者ルーカスが若い兵たちを逃がすために死ぬ。エルンストは「勝った」のではなく、「崩れていくのを止められなかった」側。
- **北を見せる。** 舞台を帝都の外、北の街道と村に移し、アイヒ中将と北方軍を出す（のちの内戦で皇女の側の総大将）。北の村は、南の戦争のために兵と麦を吸い上げられて飢えている。同盟の麦は、北の村の子どもも食べている。
- **共和国の腹黒さを見せる。** 共和国の情報部は、用が済んだ同盟を自分で売る。「共和国は、帝国が自分で割れるのを待っている」ことを、ルーカスの最期の言葉でエルンストに伝える（内戦編への橋）。
- **二人の主人公。** エルンストとルーカスの場面を、毎話交互に見せる（ユーザー決定）。プレイヤーは第9話からルーカスの顔と名前を知っているが、エルンストたちは最後まで「黎明」としか知らない。ルーカスが共和国軍の少佐だということも、プレイヤーには第9話の終わりに見せる（共和国の情報部の手紙）。
  - ルーカスの側の場面は、本拠（山の修道院）が中心。若い兵に読み書きを教える、評議会で過激な一派を抑える、共和国からの手紙を一人で読む、など。

## 第9話「北の街道」

**主役：アイヒ中将（初登場）、ルーカス（初登場）、ブルーノ。（再登場）同盟の隊長**

1. **序（地図。印：北の街道）**：帝都を追い出されるように出たファルケン大隊は、同盟の部隊の拠点を探して北の街道を上る。北は、帝国でいちばん貧しい土地。
1b. **山の修道院（ルーカスの初登場）**：ドルン公国との境の山の中の古い修道院。同盟の本拠で、若い兵の訓練所。指導者「黎明」＝ルーカス・ハルトが、下町から来た若者たちに字を教えている。穏やかで、よく笑う。
   - 評議会：過激な一派の頭目（新キャラ）が「倉庫ではなく、貴族そのものを焼くべきだ」と迫る。ルーカス「おきては変えない。民の怒りは、民を殺した瞬間に、我々に向く」。頭目は黙って席を立つ（第10話の前振り）。
2. **北の宿場町**：麦の値は帝都の倍。村の子どもがやせている。ブルーノが（北の村の出、という案）黙りこむ。
3. **北方軍の砦（アイヒ中将の初登場）**：豪快で口が悪い平民の将軍。エルンストを「若造」と呼ぶ。「同盟を狩りに来た？　ここらの村は、同盟の麦で冬を越してる。村を焼けってんなら、俺の兵は貸さねえぞ」。南の戦争のために、北から兵と麦が吸い上げられ続けてきたことを話す。
4. **戦闘「峠の麦」**：同盟の荷車隊が、峠の村の隠し倉へ麦を運び込む。護衛は第8話の隊長の部隊。
   - 勝利条件：同盟の隊長を退かせる（第8話と同じ）。敗北条件：カラドリウスの撃墜、村の家（守るもの）を壊される（案）。
   - 途中で、北の峠を越えてきたハーゲンの部族の騎兵が村を荒らしに来る（三つ巴）。同盟の隊長は村を守るために、エルンストとの戦いを打ち切る。
   - 2〜3ターン目にアイヒ中将の北方軍が駆けつけ、部族を追い払う（味方の増援）。
5. **結**：隊長「北の村を飢えさせているのは誰だ。……覚えておけ、ファルケン」。夜、アイヒと酒を飲む。アイヒ「同盟を潰すのは構わねえ。だが、潰したあとで、北の村に何を食わせるかまで考えてる奴が、帝都に一人でもいるか」。
   - **修道院（夜）**：ルーカスが一人、封蝋の付いた手紙を読む。差出人は共和国軍の情報部。「ハルト少佐。帝都の混乱を、さらに広げよ」。ルーカスは手紙を引き出しにしまう。（ここでプレイヤーに、ルーカスが共和国軍の少佐だと見せる）
   - 帝都から知らせ。南の町で、同盟が市場を爆破した。死者が出た（第10話へ）。

## 第10話「黒い暁」

**主役：ルーカス、オットー、ハンス、同盟の隊長（名前が分かる）。（ボス）過激な一派の頭目**

1. **序（地図。印：南の町）**：「人は殺さない」というおきてを破る一派が、同盟の中から現れた。民の集まる市場を爆破し、死者を出した。帝都では「やはりテロリストだ」という声が高まる。
1b. **修道院**：ルーカスが市場の焼け跡の知らせを聞く。爆破したのは、評議会を出ていった頭目の部隊だった。ルーカスは隊長ゲオルクに命じる。「止めろ。……帝国の軍とでも、手を組んでいい」。
2. **ハンスの使い**：第8話で捕まらずに逃げたハンスが、白旗を掲げて大隊の野営地に来る。オットーが会う。隊長からの言づて：「おきてを破った連中は、もう同盟ではない。追っている相手は同じだ。今度だけ、肩を並べろ」。
3. **戦闘「市の日」**：過激な一派（評議会から離れた部隊。名は「黒い暁」の案）が、次の町の市の日を狙う。
   - 敵：過激な一派（ボス：一派の頭目。新キャラ）。
   - 同盟の隊長の部隊は、この戦闘には出ない。町の反対側の街道で、過激な一派の別働隊を食い止めている（会話と通信だけ。ユーザー決定）。戦闘中に隊長から通信が入る：「こっちは引き受けた。市場の側を頼む」。
   - 守るもの：町の人の荷車（撃てない／壊されたら負け。第3話の農民兵の仕組みを使う案）。
4. **戦闘のあと**：別働隊を退けた隊長の部隊が、町の外で大隊と落ち合う。隊長が初めて名乗る（名前は案：ゲオルク）。もとは帝国軍の下士官で、ローデン会戦の生き残り。「評議会は、黎明は、おきてを守る。……だが、もう帝都の誰も、それを信じない」。
   - オットーとハンスが、少しだけ話す。「死なないでください」「お前もな」。
   - 頭目は戦闘のあと、機体を捨てて逃げた（エルンストたちは取り逃がす）。
5. **頭目の最期（ルーカスの場面）**：山の中の隠れ家。逃げてきた頭目が「黎明、かくまってくれ。俺たちは同じ夜明けを目指していたはずだ」とすがる。ルーカスは静かに銃を向ける。「おきては、民を殺さないためにある。民を殺した者を、生かしておくおきてはない」。銃声。外で待っていた若い兵たちが、黙って目をそらす。（ユーザー決定）
   - ルーカス一人の場面：「……これで、私も人を殺した」。
6. **結**：近衛の詰所。ヴォルフの机に、差出人のない手紙が届く。同盟の本拠の場所が書いてある（第11話へ）。

## 第11話「売られた拠点」

**主役：ルーカス、同盟の隊長、ヴォルフ、エルザ**

1. **序（地図。印：ドルン公国との境の山）**：同盟の本拠は、ドルン公国との境の山の中にある、古い修道院だった。そこは、同盟に入った若者たちが読み書きと機兵の動かし方を教わる訓練所でもあった。
2. **近衛の詰所**：ヴォルフは手紙の出どころを疑いながらも、出撃を決める。貴族会議は「本拠を焼き払え」と命じる。訓練所には、まだ子どもに近い若者が大勢いる。
3. **宿舎**：エルンストは、近衛より先に着いて、若者たちに降伏させると決める。マティアス「近衛と手柄の取り合いですな」。エルンスト「手柄ではない。焼かれる前に、出てこさせる」。
3b. **修道院（ルーカスの場面）**：近衛と大隊が向かっていると知らせが入る。ルーカスは若い兵たちを裏の山道から逃がす支度をさせる。自分は残ると言うルーカスを、ゲオルクが止める。「あんたがここで死んだら、同盟は終わる。……門は、俺が守る」。
4. **戦闘「修道院の門」**：
   - 修道院を守る同盟の部隊（隊長ゲオルク）と戦う。
   - 決まったターンに、反対側からヴォルフの近衛が着く。近衛は降伏を待たずに修道院を攻める（近衛より先に、修道院の門まで味方の誰かが着けば、若者たちが降伏する。第7話のターン制限の仕組みを使う案）。
   - 隊長ゲオルクは、若者を逃がす時間を稼ぐために退かず、最後まで門を守って倒れる（死ぬ）。
5. **戦闘のあと**：降伏した若者たちの中に、ハンスがいる。オットーが手を引いて出す。ヴォルフ「……甘いな、ファルケン。だが、今日は貴様のやり方のほうが早かった」。エルザ「少佐、それは褒めているんですか」。
6. **手紙の出どころ**：フェリクスが、ヴォルフに届いた手紙の紙と封蝋を調べる。沿岸都市の商会の紙。共和国の金が同盟に流れていた、同じ道筋だった。**同盟を帝国に売ったのは、共和国自身だった。**
7. **結**：山の奥の隠れ家。ゲオルクの死を知ったルーカスのもとに、共和国の情報部からの最後の命令書が届く。「同盟の役目は終わった。残った部隊で帝都を焼け。帝国の目を南からそらせ」。ルーカスは、命令書を火にくべる（第12話へ）。

## 第12話「夜明けの終わり」

**主役：ルーカス、アイヒ中将、エルンスト**

1. **序（地図。印：北の古い砦）**：共和国に見捨てられた同盟の残りの部隊は、北の山の古い砦に集まった。帝都を焼けという命令には、従わなかった。
2. **北方軍の陣**：北方軍とファルケン大隊が砦を囲む。貴族会議からは「一人残らず討て」。アイヒ「俺の管区で、北の村の若いのを皆殺しにしろってか。……若造、お前はどうする」。エルンスト「降伏した者は、北方軍で預かってください」。アイヒ「預かるだけじゃねえ。冬を越させてやる」。
2b. **砦の中（ルーカスの場面）**：残った兵たちに、ルーカスは初めて自分の正体を話す。共和国軍の少佐であること、共和国が同盟を売ったこと。「私を信じてついてきたなら、最後に一つだけ命令を聞け。……生きて、降れ」。古参の兵の何人かは、それでもルーカスと残ると言う。
3. **ルーカスの使い**：ルーカスから、降伏の条件が届く。「兵たちの命を保証するなら、砦の門を開く。ただし、私だけは降らない」。
4. **戦闘「最後の砦」**：
   - ボス：ルーカスの専用機（新しい機体。共和国の将校用の機体を、夜明けの色に塗ったもの）。
   - 砦の中から、降伏の合図を待つ若い兵たちの機兵が少しずつ出てくる（撃ってはいけない機体。第3話の仕組みを使う案）。最後まで従わない古参の兵だけが、ルーカスと一緒に戦う。
   - アイヒの北方軍が、途中から味方の増援として着く（案）。
5. **ルーカスの最期**：撃破された機体の中で、ルーカスは助けを断る。エルンストに、共和国の議会が何を待っているかを話す。「共和国は、帝国に攻めては来ない。……帝国が、自分で割れるのを待っている。その日は、もう近い」。
   - 同盟は、ここで消える。ルーカスとエルンストの因縁は強調しない（ユーザーの希望）。ルーカスの言葉は、内戦編への前振りとして使う。
6. **結**：降伏した若者たちは、北方軍の預かりになり、北の村で冬を越すことになる。ハンスもその中にいる。アイヒ「若造。お前とは、また会いそうだな」。
   - 帝都から早馬。（案）**皇帝が倒れた。** 内戦編へ。
