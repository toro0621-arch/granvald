# 帝国編 後半「内戦編」 ざっとした流れ（C ベースに A を混ぜた案）

2026-11-02。ユーザーの希望で、3パターン（`civil-war-patterns.md`）のうち **C「庶子の旗」をベースに、A「天秤の冠」を混ぜた** 流れ。
名前・話の題・細かい設定はすべて案。第12話「夜明けの終わり」の結び（皇帝が倒れた）から続く。

**決まったこと（2026-11-02 ユーザー）**：この流れで進める。リディアの見せ場を1か所入れる（第18話の案）。共和国編のことはいったん置いておく。結末（結婚か婚約か、など）は終わりが近づいたら決める。今はこの方向でよい。

---

## 芯

- **C から（ベース）**：エルンストの出生（皇帝の庶子）が、内戦の真ん中で暴かれる。平民の兵や北の民がエルンストを帝位に担ぎ、エルンスト自身が「旗」にされてしまう。エルンストは担がれることを拒み、自分を担ぐ過激な者たちを自分の手で止める。最後は皇女とユリウスが結ばれて、二つの家が一つになる。
- **A から（混ぜるもの）**：
  - 一進一退。両方の大将が一度ずつ捕らえられ、交換される。
  - 勝った側が傲慢になると、味方が離れる。
  - 最後は剣だけでなく、「約束の文書」（皇帝の力をしばる帝国憲章）で終わる。
  - 敵の総大将シュタール元帥は、戦場で倒れる。
- **参考の型**：
  - 薔薇戦争：陣営を行き来する「王を作る男」＝宰相ヴェルナ。最後は二つの家の結婚で一つになる。
  - カスティーリャ内戦：庶子の兄と、正統な跡継ぎの争い。
  - フス戦争：民の運動の穏健派が、過激派を討つ。
  - イングランド無政府時代：女の跡継ぎに一度は忠誠を誓った貴族たちが、男のいとこにつく。両方の大将の捕縛と交換。最後は和約。
  - バロン戦争：王の力をしばる文書。改革派の大将が王を捕らえる。

## 流れ（第13〜23話、11話の案）

### 序盤：割れる帝国（第13〜15話）

**第13話「空の玉座」**
- 皇帝が息を引き取る。
- 皇帝は生前、貴族会議の全員に「皇女を跡継ぎとする」と誓わせていた。しかしユリウスの側は「病の床で言わされた誓いだ」「女帝の前例はない」と言って、帝都を押さえる（無政府時代の、誓いを破った貴族たちの型）。
- 皇女マリアンネとリディアを帝都から逃がす。
- 戦闘：帝都の城門を抜ける脱出戦（皇女の馬車を守る）。追ってくるのはヴォルフ。ヴォルフの1機目の専用機。

**第14話「北の峠」**
- 北へ逃れた皇女を、アイヒの北方軍が迎える。
- 北方軍を南へ動かせば北の峠が空く。アイヒは、ハーゲン族長国の若い族長と、峠を荒らさない約束を取りつける（第9話の部族の件の回収）。
- 戦闘：ユリウスの側の先遣隊の追撃を、峠の砦で迎え撃つ。

**第15話「破られた誓い」**
- 帝都でユリウスが即位の儀を急ぐ。シュタール元帥は「帝国の前例を守るため」として、ユリウスの側につく。
- 貴族たちはどちらにつくかで割れる。皇女に誓いを守った小さな伯爵家の城が、ユリウスの側に囲まれる。
- 戦闘：伯爵家の城の救援。

### 中盤：一進一退と、暴かれた血筋（第16〜19話）

**第16話「捕らわれた皇子」**（A）
- 皇女の側の大勝。アイヒの北方軍の精鋭が、ユリウスの本陣を突き、ユリウス本人を捕らえる（バロン戦争の、改革派の大将が王を捕らえた戦いの型）。
- エルンストはユリウスを礼をもって扱う。牢の前で、幼なじみのユリウスとマリアンネが言葉を交わす（のちの結婚の前振り）。
- 戦闘：ユリウスの本陣を突く。ボスはユリウスの機体（撃墜されずに降る）。

**第17話「驕る勝者」**（A＋C）
- 勝った皇女の側の貴族たちが傲慢になり、ユリウスについた領地を略奪する。帝都の民と中立の貴族が、皇女の側から離れていく（無政府時代のマティルダが、ロンドンで嫌われて追い出された型）。
- その機をとらえて、宰相ヴェルナがエルンストの出生の証拠を世に出す。「皇女の側の大隊長は、陛下が平民の女に産ませた庶子だ」。
- 皇女の側に動揺が走る。
- 戦闘：略奪をした皇女の側の貴族を、エルンストが自分で止める（味方の貴族と戦う）。

**第18話「庶子の旗」**（C）
- 平民の兵と北の村の民の一部が、「平民の母を持つ皇子」に熱狂し、勝手にエルンストを帝位に担ぎ始める（ノルウェー内戦の、貧しい者たちの軍の型）。
- 皇女の側が、皇女派とエルンスト派に割れかける。レオ・クラーラ・ニーナ（平民出の将校たち）の気持ちも揺れる。
- **リディアの見せ場（案）**：
  - エルンストを担ぐ兵たちが「皇子を帝位に」と陣で騒ぎ、皇女の天幕を囲みかける。そこへリディアが一人で出ていく。
  - リディアは、ファルケン家の娘として、エルンストが血のつながった兄ではないことを初めて知った直後。それでも兵たちの前で言う。「血がどうであれ、あの人は私の兄です。兄は、旗になるために剣を取ったのではありません。……兄を、あなたたちの旗にしないで」。
  - 後宮で好奇心のままに暮らしていた妃が、初めて自分の言葉で人を動かす場面。兵たちは引き、皇女派とエルンスト派が割れずにすむ。
- その混乱をついて、シュタール元帥の反撃。アイヒが捕らえられる（A）。
- ヴォルフは、この戦いで副官のエルザを失う（ヴォルフが大切な人を失っていく型）。
- 戦闘：シュタールの本軍の反撃に耐える撤退戦。

**第19話「聖堂の取り引き」**（A）
- 聖ルミナ教国の聖堂で、捕虜を交換する（ユリウスとアイヒ。無政府時代に両方の大将が交換された型）。
- 交換の場で、宰相ヴェルナが皇女の側へ寝返る（王を作る男）。「庶子の旗を立てれば、帝国はあなたのものだ」とエルンストにささやく。
- エルンストは断る。
- 戦闘：交換の場を壊そうとする者たち（エルンストを帝位に担ぐ過激な一派の前触れ、またはヴォルフの独断）との戦い。

### 終盤：旗を降ろす（第20〜23話）

**第20話「旗を降ろせ」**（C＋フス戦争）
- エルンストを帝位に担ぐ過激な一派が、皇女を除こうと動く（皇女を狙う刺客）。
- エルンストは「私は旗ではない」と言い、自分を担ぐ者たちを自分の手で止める（フス戦争の、穏健派が過激派を討った型。暁編のルーカスとラザルの話と重なる）。
- 中には、エルンストに好意を持っていた北の村の若者もいる。
- 戦闘：味方だった者たちと戦う。

**第21話「老将の最期」**（A）
- 決戦。皇女の側とユリウスの側の本軍がぶつかる。
- シュタール元帥は、「秩序を守る」という信念のまま、戦場で倒れる。最期にアイヒと言葉を交わす（ローデン会戦の上官と部下。第9話の前振りの回収）。
- 南の国境で、共和国の強硬派が動き始めたという知らせが届く（早く終わらせなければならない時限）。

**第22話「狼の最期」**（C）
- ヴォルフはエルザを失い、エルンストが皇帝の子だと知り、忠誠も大義も捨てて、執念だけでエルンストに挑む。
- 最後の専用機に乗り、エルンストとの最後の決闘で死ぬ（STORY.md の、憎みきれない哀しいライバルの最期）。

**第23話「二つの冠」**（A＋C）
- ユリウスとマリアンネが、戦場の真ん中で向き合う。
- 宰相ヴェルナは、最後にもう一度寝返ろうとして、見抜かれて倒れる（薔薇戦争の「王を作る男」の最期の型）。
- 聖ルミナ教国の仲立ちで和約を結ぶ。
  - 皇女とユリウスが結婚して、二つの家を一つにする。女帝の前例のなさと、男系の筋が同時に片づく（C）。
  - 皇帝の力をしばる「帝国憲章」を結ぶ。貴族会議の権利を残しつつ、平民の代表も会議に加える。改革の中身はぼかす（A）。
- エルンストは皇族に戻らない。名もない母の墓に、母の名を刻む（STORY.md の最後の場面の案）。
- 南の国境の共和国との話（終戦協定）は、共和国編との合流へ。
