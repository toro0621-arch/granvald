# 帝国編 第9話「北の街道」台本

> まだゲームに入れていない。あらすじは `docs/scenario/empire-09-12-plot.md`。

暁の同盟編の1話目。主役はアイヒ中将（初登場）、ルーカス（初登場）、ブルーノ。
暁編はエルンストの側とルーカスの側の場面を交互に見せる（ユーザー決定）。プレイヤーにはルーカスの顔と名前、共和国軍の少佐であることをこの話で見せる。エルンストたちは「黎明」としか知らない。
アイヒ中将の副官「ハイデ大尉」、過激な一派の頭目「ラザル」、同盟の隊長の名「ゲオルク」（この話ではまだ名乗らない）はすべて名前の案。

書き方：`> （背景：…）` は会話の背景画、`> （曲：…）` は流す曲、`> （印：…）` は大陸の地図に出す場所の印。地の文の `>` はナレーション。

> （背景：大陸の地図　印：北の街道）

## マップ「峠の村」（案）

- 10×12。北に峠（山・崖）と、峠を下る道。真ん中より上に村（市街のマス。守る村）。南から味方が北へ上る。
- 同盟の部隊：前衛（盾）3〜4機と後衛（砲）1〜2機、隊長。荷車は絵だけ（村の中に置く）。
- 2ターン目の敵フェイズに、北の峠からハーゲンの略奪隊の機兵が3〜4機出る（敵の増援）。
- 3ターン目の味方フェイズに、アイヒの北方軍が南東から2〜3機着く（味方の増援。プレイヤーが動かせる）。アイヒ機は1機目。
- 勝利条件：同盟の隊長を退かせる（第8話の retreat と同じ）。ハーゲンの略奪隊を全部倒さなくても勝てる。
- 戦闘の背景：北の村（新しく描く。なければ村の背景を寒々しく色を変える）。

### この戦闘で新しく要る仕組み（案）
1. **味方の増援をプレイヤーが動かす**：アイヒの北方軍（第4話の大隊の到着と同じ仕組みで足りる）。
2. **同盟とハーゲンの三つ巴**（なくてもよい）：2ターン目から、同盟の機兵がハーゲンの機兵も狙うようにする。難しければ、同盟とハーゲンはどちらも「敵」のままで、会話だけで三つ巴に見せる。

## メモ
- 第8話から直接つながっているので、冒頭の地図のナレーションはあらすじを兼ねる。
- 話のレベルは9（`lv:9`）。
- 会話の曲（案）：修道院・宿場町・砦は「作戦会議２」。峠の村の戦闘開始は「戦闘準備」。敵フェイズは「炎神の吐息」（同盟が相手の話）。ルーカスの場面に専用の曲を付けてもよい（案）。
- ルーカス：30代半ば（案）。穏やかで、よく笑う。若者たちに字を教えている（この世界の字は、ヨーロッパの言葉のような表音文字。漢字のように形に意味のある字ではない。ユーザーの指摘）。おきて「人は殺さない」を守る理由を、きれいごとではなく「民の怒りが自分たちに向くから」と説明する（理想家だが、計算もできる）。
- この話でプレイヤーに見せること：ルーカスが「黎明」であること。共和国軍の情報部（ヴェイン。名前は案）から命令を受ける少佐であること。命令のすべてには従っていないこと。
- アイヒ中将：豪快で口が悪い。「閣下はよせ」。ローデン会戦の生き残りで、皇帝の勅令の最初の組の平民将校（STORY.md）。皇帝に借りがあるので、エルンストを見に来た。
- ハイデ大尉（名前は案）：アイヒの副官。北方軍の平民の女性将校。アイヒの口の悪さを、表情を変えずにたしなめる。
- ラザル（名前は案）：過激な一派の頭目。評議会でルーカスに逆らい、出ていく（第10話の前振り）。
- 市場が爆破された町「ヴェストブルク」は名前の案。

### 必要な絵（案）
- 顔グラ：ルーカス、アイヒ中将、ハイデ大尉、ラザル、同盟の少年（なくてもよい。同盟兵の顔の使い回しでも可）。ハーゲンの部族兵はモブの顔グラがある。
- 機体：アイヒの専用機（北方軍の指揮官機）、北方軍の量産機（ゼクトの寒冷地仕様、色違いでも可）、ハーゲンの機兵（騎馬民族らしい軽い機兵）。同盟の機兵は第8話のエスタ。
- 会話の背景：修道院の教室、修道院の評議の間（夜も）、北の宿場町、北方軍の砦（昼・夜）、峠の村。
- 戦闘の背景：北の村（寒い山の村）。
- マップ：峠と村。今のタイル（山・森・村）で作れる。
