# エスタリス共和国の政治構造（案）

2026-11-02。ユーザーが挙げた、中世〜近世の財閥・商業国家の争いと軍事との関係をもとにした、共和国の政治のたたき台。
名前・細かい設定はすべて案。共和国編はいったん置いておく（ユーザー）ので、今は「帝国編の裏で共和国がどう動いているか」の土台として使う。

前提（STORY.md）：
- 共和国は議会制。議員が軍需企業と癒着し、派閥の利権で政策が決まる。上は選挙と献金だけがうまい無能、現場は叩き上げの中堅士官と官僚が有能。
- 戦争が続くのは、企業と議員が儲かるから。
- 議会は「強硬派」と「慎重派」に割れている。
- 軍の情報部（ヴェイン大佐）が暁の同盟を動かしていた。金は沿岸都市の商会から帝都の両替商へ流れた。

---

## 1. 骨組み：議会の上に、四つの大商家

共和国の議会は、表向きは選ばれた議員が国を動かす。だが、議員の多くは四つの大商家（財閥）に養われていて、議会の争いは実際には商家どうしの争い。

| 商家（名前は案） | 元にした歴史 | 何で稼ぐか | 軍事との関係 | 議会での立場 |
|---|---|---|---|---|
| **アークライト家** | フッガー家 | 鉱山・金属・金貸し | 機兵の骨組みの金属を一手に握る。国にも、外国にも金を貸す（帝国の貴族にも、裏で） | 強硬派の金庫。戦が続くほど儲かる |
| **セルヴィア家** | メディチ家 | 首都の銀行と、首都の政治 | 首都の市政と議長の椅子を握る。軍の予算は議会を通すので、軍にも顔がきく | 今の議会の主流。表向きは中立、実は両派に金を配る |
| **ポルトレア商会** | ヴェネツィア共和国 | 東の港の海運と交易 | 港の商会の金で、共和国の海軍の大半を造り、養っている（「国の海軍」だが、実態は商会の海軍） | 慎重派。戦で航路が荒れるのを嫌う。帝国とも本当は商売がしたい |
| **カルヴェン商会** | ジェノヴァ共和国 | 西の港の船主と、傭兵 | 船主たちが傭兵の機兵部隊を抱え、国や他国に貸し出す。共和国の機兵の流し先（暁の同盟の機兵も、ここからドルン公国の山道へ） | 強硬派。戦場がなければ傭兵が食えない |

- **もう一つの家**：**ドレイク家**（アルビッツィ家が元）。首都の古い名門で、セルヴィア家に議長の椅子を奪われた旧主流。巻き返しをねらっている。

## 2. 四つの争い方

ユーザーの分類を、そのまま共和国の中の争いに当てはめる。

### 政治的な権力闘争（メディチ家 vs アルビッツィ家）
- **セルヴィア家 vs ドレイク家**：議長の椅子と首都の市政をめぐる争い。
- 歴史では、アルビッツィ家がメディチ家の当主を追放し、翌年メディチ家が戻ってアルビッツィ家を追い落とした。
- 共和国でも、選挙・追放・復帰がくり返されている。議会の多数を取ったほうが、政敵を「国家への背信」で首都から追放する。

### 商業圏の奪い合い（ジェノヴァ vs ヴェネツィア）
- **ポルトレア商会 vs カルヴェン商会**：東の海と西の海、ミレア諸島王国との交易、沿岸都市連合への影響力をめぐる争い。
- ポルトレアは海軍（国の船）で、カルヴェンは傭兵（雇われの機兵）で戦う。
- 二つの商会は、ときに共和国の外で、それぞれ雇った兵どうしで小さな戦争をしている（キオッジャ戦争のような、商会どうしの海戦の案）。

### 暗殺・クーデター（メディチ家 vs パッツィ家）
- **セルヴィア家の当主を狙う陰謀**：歴史では、ライバルの銀行家パッツィ家が教皇の後ろ盾を得て、大聖堂のミサの最中にメディチ家の兄弟を襲った。弟は殺され、兄は生き延びて、陰謀に加わった者たちを処刑した。
- 共和国でも、ドレイク家とカルヴェン商会が手を組み、セルヴィア家の当主を議会の開会式で襲う（案）。当主は生き延び、報復で強硬派の一部が粛清される。
- これが、共和国の議会の力関係を一気に変える事件になる（使いどころは下の「帝国編とのつながり」）。

### 金融競争・経営破綻（バルディ家・ペルッツィ家）
- **アークライト家の破綻の危機**：歴史では、バルディ家とペルッツィ家がイングランド王に巨額の金を貸し、王が返さなかったために両家とも潰れた。
- アークライト家は、帝国の貴族（ユリウスの側の大貴族や、宰相ヴェルナ）にも裏で金を貸している。帝国の内戦でユリウスの側が負けたり、帝国が借金を踏み倒したりすれば、アークライト家は潰れる。
- 潰れれば、共和国の金属と機兵の生産が止まり、強硬派の金庫が空になる。

## 3. 帝国編とのつながり（案）

| 帝国編の出来事 | 共和国の裏で起きていること |
|---|---|
| 第1〜5話の横流しの機兵 | 帝国の機兵の横流しは帝国の兵站局。共和国は関わっていない（関わっていたら面白い：カルヴェン商会が買い手の一つだった、の案） |
| 第8〜12話の暁の同盟 | 金はセルヴィア家の銀行から沿岸都市の商会、帝都の両替商へ。機兵はカルヴェン商会の傭兵の流し先から、ドルン公国の山道を通って。動かしたのは軍の情報部（ヴェイン大佐）で、議会の強硬派の差し金 |
| 第11話「同盟を売ったのは共和国」 | 同盟を見捨てると決めたのは、セルヴィア家（議会の主流）。同盟が民を殺した（第10話）ので、共和国の評判を守るために切った。ヴェインはそれに従った |
| 内戦編（第13〜23話） | アークライト家は、ユリウスの側の大貴族に金を貸している。ユリウスの側が負けそうになると、アークライト家の破綻の危機。強硬派は「借金を取り返すために、帝国に攻め込め」と議会に迫る（内戦の終盤の「共和国の強硬派が国境で動き始める」の理由） |
| 内戦のあいだ共和国が攻めてこない理由 | 慎重派のポルトレア商会と、主流のセルヴィア家が反対しているから。強硬派（アークライト家・カルヴェン商会）が議会の多数を取れば、攻めてくる |
| 共和国の強硬派が議会を押し切るきっかけ（案） | セルヴィア家の当主を狙う陰謀（パッツィ家の陰謀の型）。当主が倒れるか、議会が混乱した隙に、強硬派が侵攻を決める |

- 共和国も、上の商家の争いで動いていて、帝国と同じく「上は無能（または自分の家の利益しか見ない）、現場は有能」。帝国の内戦と、共和国の商家の争いを鏡にする。
- 終戦協定（物語の最後）は、帝国の皇女の側と、共和国の慎重派（ポルトレア商会と、現場の中堅士官たち）が結ぶ形が自然。戦争で儲かる商家（アークライト家・カルヴェン商会）は、停戦を嫌う。

## 4. 機体と兵（案）

- **共和国軍の量産機「エスタ」**：アークライト家の金属で、国の工廠が作る。第8話から暁の同盟が使っている機体。
- **カルヴェン商会の傭兵の機兵**：同じエスタを、商会ごとの色に塗って使う。部隊ごとに紋章が違う、寄せ集めではない、腕の立つ雇われ兵。
- **ポルトレア商会の海軍**：港を守る機兵と、船。海の話を作るなら使える（今のところ帝国編には出ない）。

## 5. 決めてほしいこと（案）

1. 四つの商家（と、ドレイク家）の名前。
2. 強硬派と慎重派の分け方（強硬派＝アークライト家・カルヴェン商会、慎重派＝ポルトレア商会、主流で両方に金を配る＝セルヴィア家）でよいか。
3. ヴェイン大佐（情報部）が、どの商家の息のかかった人か（強硬派のアークライト家、の案）。
4. 帝国編の中で、共和国の商家をどこまで見せるか（名前だけ出す／内戦編の終盤で一場面だけ見せる／見せない）。
