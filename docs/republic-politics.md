# エスタリス共和国の政治構造（裏設定・案）

> 2026-11-02：フッガー家の型は、帝国の豪商シュタインベルク家（STORY.md）に移した。共和国はメディチ家・ハンザ商人・ヴェネツィア（とジェノヴァ）の型で組む。

2026-11-02。ユーザーが挙げた、中世〜近世の商人の一族・商業国家の例をもとにした、共和国の政治のたたき台。
**帝国編では、あくまで裏設定として持っておく（ユーザー）。** 帝国編の画面には直接は出さず、共和国の動き（暁の同盟の金、内戦の終盤の強硬派の動きなど）の理由として使う。共和国編はいったん置いておく。
名前・細かい設定はすべて案。

前提（STORY.md）：
- 共和国は議会制。議員が軍需企業と癒着し、派閥の利権で政策が決まる。上は選挙と献金だけがうまい無能、現場は叩き上げの中堅士官と官僚が有能。
- 戦争が続くのは、企業と議員が儲かるから。
- 議会は「強硬派」と「慎重派」に割れている。
- 軍の情報部（ヴェイン大佐）が暁の同盟を動かしていた。金は沿岸都市の商会から帝都の両替商へ流れた。

---

## 1. 国のかたち：商人が支配階層の国（ヴェネツィア共和国の型）

- 共和国は、214年に南部の諸侯が帝国から独立して建てた国。だが四百年のうちに、土地を持つ諸侯の家は衰え、交易と金融で富んだ商人・船主・金貸しの家々が、議会の椅子を占めるようになった。
- 今の共和国の「議員」は、ほとんどが大商家の当主か、その一族か、大商家に養われた者。**商業のエリートが、そのまま国の支配階層になっている**（ヴェネツィア共和国の型）。
- 表向きは「誰でも議員になれる共和国」。実際は、選挙に勝つ金を出せる家しか議会に入れない。帝国の「生まれで決まる」に対して、共和国は「金で決まる」。

## 2. 商人が力を持つ四つの型

ユーザーの挙げた四つの型を、共和国の中の大きな家と勢力に一つずつ当てる。

### メディチ家の型：商人の一族が、事実上の支配者になる
**セルヴィア家**（首都の銀行家）
- 自分たちの銀行で資産を築く。首都の商人の金を預かり、貸す。
- 政治家や有力者との人脈を作る。議員の選挙の金を、どの派にも貸す。
- 議長の椅子を握り、政治的な主導権を取る。表向きは議員の一人だが、議会の多数は実質この家が決める。
- 共和国の外交や政策に影響を与える。帝国との冷戦の続け方も、暁の同盟を育てるか切るかも、最後はこの家の当主が決める。
- 旧主流の**ドレイク家**（アルビッツィ家にあたる古い名門）と、議長の椅子をめぐって追放と復帰をくり返してきた。

### フッガー家の型 → 帝国のほうに当てた
- 外国の王侯にも金を貸し、見返りに鉱山の採掘権や特権を得る型は、**帝国の豪商シュタインベルク家**（STORY.md）に当てた（2026-11-02。ユーザーと相談して、帝国のほうが合うとした）。帝位を金が決める内戦編で使う。
- 共和国の**アークライト家**は、国の工廠に機兵の金属と部品を納める軍需の家にする。外国には金を貸さない。戦が続くほど注文が増えるので、強硬派の金庫。帝国のシュタインベルク家から、沿岸の商人同盟を通して帝国の金属を買っている（敵国から）。

### ハンザ商人の型：国境をまたいで、戦争中でも商売をする
**沿岸の商人同盟**（「潮の組合」などの名前の案）
- 共和国の港、沿岸都市連合、ミレア諸島、そして帝国の港町にまでまたがる、商人たちの同盟。どこか一国のものではない。
- 各地の支配者と通商協定を結ぶ。帝国の毛織物、北の木材や毛皮、南の麦と酒を運ぶ。
- 帝国と共和国が冷戦でも、戦争でも、自分たちの利益を追う。
- 暁の同盟の金の通り道は、この同盟の商人たちだった（共和国の金→沿岸都市の商会→帝都の両替商）。商人たちは、何を運んでいるかを気にしない。
- 帝国の側から見れば、敵の金を運ぶ者。だが、帝国の貴族も彼らの船で贅沢品を買っているので、誰も手を出せない。

### ヴェネツィア共和国の型：商業のエリートが国を運営する
**共和国そのもの**（上の1）。
- 港の大商会の**ポルトレア商会**（東の港。商会の金で国の海軍の大半を造り、養う）は、この型のいちばん古い家。航路が荒れるのを嫌う慎重派。
- 西の港の**カルヴェン商会**（船主と傭兵の機兵部隊）とは、海の商圏を争っている（ジェノヴァとヴェネツィアの型）。カルヴェン商会は戦場がなければ傭兵が食えないので、強硬派。

## 3. 議会の力関係（案）

| 家 | 型 | 議会での立場 |
|---|---|---|
| セルヴィア家 | メディチ家 | 主流。表向きは中立、両派に金を配って舵を取る |
| ドレイク家 | アルビッツィ家 | 旧主流。セルヴィア家を追い落とす機会をねらう |
| アークライト家 | 軍需の家 | 強硬派の金庫。機兵の金属と部品で、戦が続くほど儲かる |
| カルヴェン商会 | ジェノヴァ | 強硬派。傭兵を食わせるために戦場が要る |
| ポルトレア商会 | ヴェネツィア | 慎重派。航路と交易を守りたい。本当は帝国とも商売がしたい |
| 沿岸の商人同盟 | ハンザ商人 | 議会の外。どちらにもつかず、どちらとも商売する |

## 4. 争い方（ユーザーの分類）

- **政治的な権力闘争**（メディチ家 vs アルビッツィ家）：セルヴィア家 vs ドレイク家。選挙・追放・復帰。
- **商業圏の奪い合い**（ジェノヴァ vs ヴェネツィア）：ポルトレア商会 vs カルヴェン商会。海軍と傭兵で、海の商圏を争う。
- **暗殺・クーデター**（メディチ家 vs パッツィ家）：ドレイク家とカルヴェン商会が、セルヴィア家の当主を議会の開会式で襲う陰謀（案）。
- **金融競争・経営破綻**（バルディ家・ペルッツィ家）：共和国の中ではなく、帝国のシュタインベルク家に当てた（内戦でユリウスの側に貸した金が返らなくなる危機）。

## 5. 帝国編の裏で（画面には直接出さない）

| 帝国編の出来事 | 裏で起きていること |
|---|---|
| 第8〜12話の暁の同盟 | 金はセルヴィア家の銀行から出て、沿岸の商人同盟の手で帝都の両替商へ。機兵はカルヴェン商会の傭兵の流し先から、ドルン公国の山道を通して。動かしたのは軍の情報部（ヴェイン大佐）で、強硬派の差し金 |
| 第11話「同盟を売ったのは共和国」 | 同盟を見捨てると決めたのは、議会の主流のセルヴィア家。同盟が民を殺した（第10話）ので、共和国の評判を守るために切った |
| 内戦のあいだ共和国が攻めてこない | 主流のセルヴィア家と、慎重派のポルトレア商会が反対しているから |
| 内戦の終盤、共和国の強硬派が国境で動く | 強硬派（アークライト家・カルヴェン商会）は、戦の注文と傭兵の仕事が欲しい。帝国が割れて弱った今が好機だと議会に迫る。セルヴィア家の当主を狙う陰謀で議会が乱れた隙に、侵攻を押し通そうとする（案） |
| 物語の最後の終戦協定 | 帝国の皇女の側と、共和国の慎重派（ポルトレア商会と、現場の中堅士官たち）が結ぶ形が自然。戦で儲かる家（アークライト家・カルヴェン商会）は停戦を嫌う |

- 帝国が「生まれで決まる国」、共和国が「金で決まる国」。どちらも上は自分の家の利益しか見ず、現場は有能。帝国の内戦と、共和国の商家の争いを鏡にする。
- 帝国編で画面に出すとしたら、ヴェイン大佐の手紙や、フェリクスが金の流れを追う場面で、家の名前が一言出る程度（案）。
